# Monitoring-Hikvision-NVR
Мониторинг регистратора Hikvision, а именно состояния камер, дисков регистратора, получение информации о регистраторе.

В данном шаблоне мониторига исползуется два способа:
1. SNMP для проверки и получения простых данных, чтобы быстро и просто из взять, без лишних заморочек.
2. ISAPI для получения всей основной информации о состоянии каналов, дисков и информации о регистраторе.

Для работы шаблона необходимо в макросах указать следующие данные:
1. {$HIKVISION.API.PASSWORD} Ваш пароль который используете для авторизации
2. {$HIKVISION.API.PORT} Порт через который вы подключаетесь к регистратору, по умолчанию это 80
3. {$HIKVISION.API.SCHEME} тип подключения http и https
4. {$HIKVISION.API.USER} Логин который используете для авторизации

Для простоты и удобстав я создал отдельного пользователя с правами администратора на регистраторе и при помощи него уже собираю все данные. Не советую использовать дефолтных пользователей, так как при смене пароля или имени пользователя необходимо будет править данные так же и на хосте, а со временем вы забудете об этом и будете долго разбираться почему ваш регистратор не собирает данные. 

Макросы описанные выше лучше добавлять на сам host, а не на шаблон! 

Это список того что мы мониторим или получаяем с регистратора:
Частоту CPU, Статусы каналов, Имя устройства, Версия встроенного ПО, Мак Адрес, Модель устройства, Серийный номер, Данные о подключеных дисках, Смарт дисков, IP адрес регистратора, Тип устройства NVR/DVR, Используемое колличество ОЗУ, Статус регистратора, Колличество дисков в регистраторе, Объем ОЗУ и Uptime регистратора.
